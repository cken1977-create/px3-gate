# px3-gate constitution

A job may move a named person to a named site only if a fresh evaluation against a versioned, owner-asserted pack is ok — or the move is recorded as an exception that cannot appear in a compliant export.

- Events are truth. No last-write-wins. No gate_status on Assignment.
- Compliant PDF must never include an override row.
- Packs are owner-asserted. PackFailure from day one.
- Hands have no login. No employee-vs-1099 field.
- Field answers live in FIELD.md.
